# ExpTreeLib
This is a library of Windows controls consisting of a TreeView and a ListView.  It provides functionality for navigating and manipulating the Windows Shell and file system namespaces like Windows Explorer.

This project is originally from Jim Parsells, he published it in CodeProject but that site is dead now unfortunately.  The original license is CPOL 1.02.  Later, Kai Lu updated the project.

I have taken this project and converted into c# and .net 10.  I have also added some features like ThumbNail display and mades some other fixes and optimizations.
